# AgentSoc 桌面代理 · 安装包使用说明

> 一键安装包，双击即可完成部署，无需任何手动配置。

---

## 一、安装包是什么

`AgentSoc-Proxy-Setup.exe` 是标准 Windows 安装程序（Inno Setup 打包），双击运行即可完成：

1. 安装程序到 `C:\Program Files\AgentSoc\`
2. 自动写入配置文件（上游网关、拦截域名）
3. 注册为 Windows 服务（`AgentSocProxy`，开机自启）
4. 立即启动服务

安装完成后，终端**无需任何额外配置**，AI 工具的流量自动经过安全防护。

---

## 二、安装（终端用户）

### 图形界面安装

1. 双击 `AgentSoc-Proxy-Setup.exe`
2. 弹 UAC 提示 → 点「是」（需要管理员权限装证书 + 注册服务）
3. 一路下一步，完成

安装后无任何窗口，服务在后台静默运行。

### 静默安装（域控 / 批量分发）

```cmd
AgentSoc-Proxy-Setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART
```

配合集团软件分发系统（SCCM / 域控脚本）批量下发。

---

## 三、卸载

- 控制面板 → 卸载程序 → 「AgentSoc Desktop Proxy」→ 卸载
- 或静默卸载：

```cmd
"C:\Program Files\AgentSoc\unins000.exe" /VERYSILENT
```

卸载时自动停止并删除服务、清理 hosts 条目。

---

## 四、验证安装成功

安装后，在命令行执行：

```cmd
sc query AgentSocProxy
```

看到 `STATE: RUNNING` 即成功。

或检查服务列表：

```cmd
sc queryex AgentSocProxy
```

---

## 五、配置项（运维人员）

安装后配置文件在 `C:\Program Files\AgentSoc\config.json`：

```json
{
  "mode": "explicit",
  "upstream": "http://172.17.0.200:8000",
  "target_domains": ["new-api.gaojihealth.cn", "api.openai.com", "api.anthropic.com"],
  "ca_dir": "certs"
}
```

| 字段 | 说明 |
|---|---|
| `mode` | `explicit`（显式代理，合规零风险）或 `transparent`（透明 MITM，需合规授权） |
| `upstream` | AgentSoc 网关地址 |
| `target_domains` | 透明模式要拦截的 AI 域名 |

> 当前安装包默认 `explicit` 模式（无合规风险）。切换到 `transparent` 需集团合规授权后，改配置并重启服务。

---

## 六、重新生成安装包（开发）

```bash
# 1. 编译 exe
go build -o agentsoc-proxy.exe .

# 2. 改 installer.iss 里的版本号/网关地址

# 3. 用 Inno Setup 编译
ISCC.exe installer.iss
```

产物在 `output/AgentSoc-Proxy-Setup.exe`。
